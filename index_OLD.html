Semantic Book Recommender

An end-to-end redesign of a content-based recommendation engine. Diagnostic analysis uncovered an upstream index-misalignment bug, which was corrected prior to enriching 15,000 metadata records via the Open Library API. Replacing lexical keyword matching with dense sentence-transformer embeddings and FAISS vector indices increased subject-relevance retrieval 2.3-fold over the lexical baseline, and 14.6-fold over a random floor.

Campaign Uplift & Causal Inference

Observational pre-post comparisons often confuse baseline market trends with true campaign impact. This project isolates causal uplift by constructing synthetic controls via structural time-series models, validated against GBDT and autoregressive baselines. Synthetic stress-testing verified the model's accuracy (+4.62% estimated vs. +4.21% ground truth), against naïve before-and-after and year-on-year comparisons reporting +44.8% and +43.7% respectively. Applied to live retail data, placebo tests exposed treatment selection bias, allowing the impact to be rigorously framed as an operational upper bound.

UAV Emergent-Communication Swarm

An empirical stress-test evaluating whether multi-agent reinforcement learning (MARL) communication architectures generalise to dynamic, link-fragmented topologies. Experimental runs across four random seeds demonstrated that while agents achieve high spatial coverage (73% peak), policies collapse over time. Diagnostic analysis revealed two root causes: reward instability in high-density states and a checkpoint evaluation metric that inadvertently prioritised unstable peak policies over balanced trajectories.

Ethereum Fraud & Data Forensic Analytics

An exploratory and statistical analysis investigating address behaviour on the Ethereum blockchain using non-parametric hypothesis testing and multivariable logistic regression. Data forensic checks identified two prominent label-leakage artefacts—accounting for 77% of target labels—where structural missingness (e.g., absent ERC-20 transfer logs) directly correlated with fraud class assignments. The resulting documentation establishes corrected baselines for predictive modelling on public benchmark data.

Production Phishing Detection Service

A phishing email classifier served through a containerised FastAPI application, developed alongside the measurements that establish what its performance covers. Deduplicating the corpus before splitting removes a leakage path worth half a point of accuracy. Coefficient inspection shows the legitimate class is identified partly by its provenance, and a probe set written in a contemporary register shows accuracy falling from 0.980 to 0.833 while class separation contracts by roughly two thirds. The service returns calibrated probabilities so the threshold can be set per deployment, and logs prediction metrics without message content so that drift is visible.

Research

My doctoral research addresses a primary challenge in multi-agent systems: maintaining coordinated behaviour when communication channels are noisy or lossy. I developed NoisyGraph, a framework integrating geometry-driven network topology, autoencoder-based message reliability scoring within graph attention layers, and post-training channel calibration. Evaluated on connected autonomous vehicle environments, the architecture sustains coordination as the channel degrades. Whether that behaviour transfers to a mobile topology the agents must maintain themselves is the open question the UAV continuation investigates. This work comprises two peer-reviewed publications and a comprehensive survey under review at JAAMAS.
